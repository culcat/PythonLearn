# Документация проекта: Python & FastAPI Obsidian Vault (От 0 до Pro)

## 1. Обзор проекта
Данный репозиторий представляет собой полноформатный интерактивный учебник по языку программирования **Python (3.12–3.14+)** и фреймворку **FastAPI (с Pydantic v2 и SQLAlchemy 2.0)** в формате базы знаний **Obsidian Vault** с практическими проверочными заданиями и автотестами.

## 3. Стандарты оформления материалов (Obsidian Flavored Markdown)
- **YAML Frontmatter**: Каждая заметка снабжена метаданными (`title`, `module`, `difficulty`, `tags`, `prerequisites`).
- **Связность (Wikilinks)**: Все концепции и соседние главы связаны двусторонними ссылками `[[Note_Name|Описание]]` для построения информативного графа в Obsidian.
- **Визуализация**: Архитектура, жизненный цикл запросов, работа памяти и алгоритмов проиллюстрированы диаграммами `mermaid`.
- **Callouts**: Важные нюансы, предупреждения о безопасности и советы по производительности выделены блоками `> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`.

## 4. Практические задания и система тестирования
Каждая из 30 тем завершается разделом с практическим заданием и ссылкой на соответствующий `.py` файл в каталоге `exercises/`.
В каждом `.py` файле:
1. Приведено подробное техническое задание в docstring.
2. Описаны строго типизированные функции/классы для реализации учеником (а также эталонная реализация с переключением или проверкой).
3. Встроен набор модульных тестов на базе стандартного `unittest.TestCase` (также полностью совместимый с `pytest`).
4. Тесты в модулях 04–06 проектируются так, чтобы проверять архитектурные паттерны FastAPI, валидацию, DI-контейнер, асинхронные репозитории, JWT/Auth, Rate Limiting и Clean Architecture даже в изолированном окружении без поднятия внешних СУБД (in-memory SQLite / тестовые двойники), а при установленном `fastapi`/`pydantic` поддерживают и прямую интеграцию.

### Команды для запуска проверок
Запуск конкретного упражнения:
```bash
python3 exercises/01_basics/ex_01_syntax_types.py
```
Запуск всех тестов учебника:
```bash
python3 run_all_tests.py
```

## 5. Git-поток и разработка через субагентов
Учебник разработан модульно:
- Каждый из 6 тематических блоков создается выделенным субагентом в собственной изолированной Git-ветке (`feat/module-01-basics`, `feat/module-02-oop-typing`, и т.д.).
